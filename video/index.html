✳ 02 / Phrases

Write the keyframe
in the class.

Each frame is an offset and a value, separated by a pipe. No @keyframes block. No stylesheet edit. No runtime.

A PHRASEHTML 
<div class="animate-scale-[0:0.5|50:1.1|100:1]
  animate-opacity-[0:0|50:1|100:1]
  animation-duration-[2600ms]
  animation-iteration-count-infinite">
  Gather, overshoot, settle.
</div>
0% · 50% · 100%
YOUR FIRST COMPOSITIONHTML 
<div class="animate-rotate-45
  animate-scale-110
  animation-duration-[800ms]/rotate
  animation-duration-[1200ms]/scale
  animation-direction-alternate
  animation-iteration-count-infinite">
  Make your move.
</div>

✳ 03 / Properties

Motion,
atom by atom.

Rotation takes 800ms. Scale takes 1200ms. The slash scopes a control to one property's slot, and Jumi assembles the CSS.

/rotate
/scale
Two rhythms. One element.

✳ 04 / Stagger

Start a
chain reaction.

The parent sets the rhythm. Each child owns its motion. Tailwind's *: variant does the rest. 

<ul class="animate-stagger-forward-[160ms]/3
          *:animate-fade-in-up">
animate-stagger-forward-[120ms]/7
One 0ms
Two 160ms
Three 320ms

✳ 05 / The build

No runtime.
Just CSS.

Jumi generates CSS through Tailwind at build time. The browser's own engine runs the motion. There is nothing of Jumi to download.
