Aliased /[N] Animations

Give a per-value animation a NAME — not a percentage — with the /[...] modifier (e.g. animate-width-32/[1] → keyframe jumi-width-1). Aliases replace the opaque auto-generated id, so several animations on the same element coexist as independent self-timed slots, each timed with animation-delay-{ms}/[{attr}.{N}] and animation-duration-{ms}/[{attr}.{N}]. A delayed alias takes over its property when it fires, so aliases chain into a sequence.

Aliased blend

width 24 then 32; [2] takes over at 500ms

Per-alias delay

scale.1 delayed 1000ms

Per-alias duration

rotate.1 runs 3000ms

[1] is scoped per property
