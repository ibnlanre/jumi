# Studio authoring pass

Base declarations live on SceneNode.base as optional, authored CSS property/value pairs. Existing source CSS remains intact; a deterministic base CSS serializer appends per-node rules. The same text is used in the sandbox and export. Base inspection synchronously applies a temporary positive animation delay with no fill to read underlying values, then removes that rule. It never replaces CSSAnimation effects, preserving browser ownership when motion classes change. It never stores computed values as the project model. New tracks can contain only an end frame so native CSS interpolates from the actual underlying base value.

Jumi now separates named instances of identical phrase definitions. Studio identity is node + motion name + property/phrase; shared-name property tracks share timing. Audition state (Scene/Element/Motion/Base, mute, solo) lives outside the project. The sandbox filters only its working motion classes, preserving exact public Jumi output for each audible instance. Global playback restores Scene scope; mute/solo are explicit workspace controls and never export.

The timeline uses a row model with fixed numeric row heights. Rail and time content are independent DOM columns; only the time column scrolls horizontally. A single outer vertical scroll container moves both columns. Ruler and rail heading are sticky vertically. The horizontal viewport clips its independently wide time content, and a persistent bottom horizontal scroller controls its scrollLeft. Rail resizing never changes pixels per second. Zoom changes only time width.

Base controls are conservative and SVG-tag-aware. HTML: dimensions, translate, rotate, scale, origin, opacity, and positioned offsets when meaningful. SVG: shape-appropriate geometry, paint and transforms. Moving writes CSS translate; corner scaling writes scale; rotation writes rotate. All are visible base declarations, with no wrapper transform or path rewriting. Direct gestures enter Base audition and use browser-measured invertible 2D coordinate bases; unsupported 3D/path/non-numeric transforms keep exact text editing. One gesture commits one history entry.

Appearance is a System/Light/Dark workspace preference. Canvas artwork remains project content; surrounding workspace/grid tokens change with appearance. Origin handles appear only when explicitly enabled, focused, or a transform motion is being inspected. Stored manual viewport coordinates are respected on restore.

Verification retains the complete existing browser gate and extends it for themes, independent rail scrolling/row alignment, audition non-serialization, named identical phrases, base round-trip/underlying keyframes, direct gestures/undo and contextual origin. Final output is independently recompiled and sampled outside Studio.
